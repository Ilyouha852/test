# Support_Bot_IST

Репозиторий для проекта Бот Поддержки

Чтобы у всех всё заработало клонируйте репозиторий к себе;
Потом утановитие все зависимости через npm install, если не сработает, то через yarn;
Потом напишите notepad .env, ведь необходим этот файл, а он в гитхаб не комитится;
После пропишите туда:;
JWT_SECRET=super_secret_jwt_key_for_development_12345;
PORT=3007;
NODE_ENV=development;

И всё заработает!;
