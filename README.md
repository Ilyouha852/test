# Support_Bot_IST

Репозиторий для проекта Бот Поддержки<br/>

Чтобы у всех всё заработало клонируйте репозиторий к себе<br/>
Потом утановитие все зависимости через npm install, если не сработает, то через yarn<br/>
Потом напишите notepad .env, ведь необходим этот файл, а он в гитхаб не комитится<br/>
После пропишите туда:<br/>
JWT_SECRET=super_secret_jwt_key_for_development_12345<br/>
PORT=3007<br/>
NODE_ENV=development<br/>

И всё заработает!<br/>
